
# Medconnect

## Description
Plateforme web de gestion des disponibilités des médecins
et des rendez-vous médicaux.

## Fonctionnalités principales
- Gestion des médecins
- Gestion des comptes médecins et utilisateurs
- Recherche de médecins
- Gestion des rendez-vous

## Technologies
- HTML
- CSS
- JavaScript
- Git et GitHub

## Installation
```bash
git clone https://github.com/ChaiXwX/Medconnect.git
```
Ouvrir `index.html` dans un navigateur.
